🎯 Interactive Gradient Descent Activity

Train a linear model to learn the relationship y = 2x

1. Control the Model

Loss44.000
dw-44.000
db-6.000
y_pred = wx + b

dw = (-2/n) Σ[x(y - y_pred)]
db = (-2/n) Σ(y - y_pred)

w = w - α(dw)
b = b - α(db)

2. Watch the Prediction Line

What is happening?

At w = 0 and b = 0, every prediction is 0. The errors are large, so the gradient tells the model to increase the weight.

3. Student Activity

  1. Start with w = 0 and b = 0. What are the predictions?
  2. Click One Gradient Step. What happens to the weight and loss?
  3. Observe the value of dw. Is it positive or negative?
  4. Click Train 20 Steps. Does the prediction line move closer to the data?
  5. Increase the learning rate. What happens?
  6. Set the learning rate very small. What happens to learning?
  7. Try to obtain a model close to y = 2x.

Learning goal: Understand that the gradient tells the model the direction of change, while the learning rate controls the size of the change.
