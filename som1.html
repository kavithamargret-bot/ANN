📐 SOM Weight Update Rule

Wnew = Wold + α × (X − Wold)

W = neuron weight vector
X = input vector
α = learning rate

📚 What is happening?

  1. An input vector is selected from the dataset.
  2. The Euclidean distance between the input and every SOM neuron is calculated.
  3. The neuron having the smallest distance becomes the Best Matching Unit (BMU).
  4. The BMU and its neighboring neurons are identified.
  5. The weights of the BMU and neighbors are moved closer to the input vector.
  6. The process is repeated for several epochs.
  7. Eventually, similar input patterns become organized near each other on the SOM.
